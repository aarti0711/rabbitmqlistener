RabbitMQ Listener Project
Overview

This project demonstrates how to use RabbitMQ with Java + Spring Boot for message-driven communication between services.

It includes:

Topic Exchange configuration
Queue creation
Binding Queue with Exchange
Message Producer
Message Listener (Consumer)

RabbitMQ helps applications communicate asynchronously using messages.
Start RabbitMQ Server
Windows Command
rabbitmq-server
Enable Management Plugin
rabbitmq-plugins enable rabbitmq_management

RabbitMQ Management UI:

http://localhost:15672
